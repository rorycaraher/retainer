# No push notifications for background sync

Android restricts apps from holding a persistent connection while backgrounded, so truly instant sync to a closed/backgrounded app would require Firebase Cloud Messaging (FCM) to wake it on each remote change. We deliberately do not use FCM or any push notification service: the app syncs over its WebSocket connection whenever it's open/foregrounded, and simply catches up on next open otherwise. This project exists specifically to be self-hosted and private, and FCM would route a "something changed" signal for every note edit through Google's infrastructure — a dependency and metadata leak that undermines the reason for self-hosting this instead of using a third-party notes service. The case FCM would improve (seeing an update live while not looking at the app) is a minor win for a single-user notes app compared to that cost; sync-on-open with a fast WebSocket catch-up covers the case that actually matters.
